# Mobile-Controlled Smart Cleaning Robot

## Overview
This project is a smart cleaning robot controlled via mobile application using Bluetooth.

## Hardware Used
- Arduino Uno
- HC-05 Bluetooth Module
- L298N Motor Driver
- DC Motors
- Ultrasonic Sensor

## Software Used
- Arduino IDE
- Android Studio

## Features
- Manual control via mobile
- Obstacle detection
- Smart cleaning mode

## Future Scope
- IoT based WiFi control
- AI-based path planning
