# FlexiClean – Smart Cleaning Robot

## About
FlexiClean is an Arduino-based, mobile-controlled cleaning robot designed for floor cleaning, obstacle detection, and controlled water dispensing. Wall cleaning is planned as a future enhancement.

## Features
- Bluetooth-based mobile control
- Ultrasonic obstacle detection
- Motorized movement
- Rotating mop/brush mechanism
- Controlled water dispensing
- Future scope: Wall-climbing capability

## Technologies Used
- Arduino Nano
- Embedded C/C++
- HC-05 Bluetooth Module
- HC-SR04 Ultrasonic Sensor
- Geared Motors and Motor Driver
- Water Pump and Cleaning Mechanism
- MIT App Inventor / Android Studio

## Working Principle
1. The mobile app sends commands through Bluetooth.
2. The HC-05 module receives commands and communicates with the Arduino.
3. The Arduino controls the robot's movement.
4. The ultrasonic sensor detects obstacles.
5. The cleaning mechanism and water pump operate according to the implemented controls.

## Project Status
Currently focused on developing the floor-cleaning prototype and mobile-control system.
